# Run and deploy this AI Studio app

This repository includes everything you need to run the app locally.

View in AI Studio: https://ai.studio/apps/drive/1YklQS2Htgv8ey1gK_gnai32tQ-6mEVyh

## Run locally

**Prerequisite:** Node.js

1. Install dependencies:
   `npm install`
2. Set `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key.
3. Start the app:
   `npm run dev`

## Quick app summary

This app is a playful Valentine invitation flow:
- asks, "Will you be my Valentine?"
- celebrates **YES** with confetti and animation
- keeps things playful with a moving **No** button
